# Yue Yu website redesign — local draft

This checkout is connected to `yyucuhk/yyucuhk.github.io`, but the redesign exists only on the local `redesign-draft` branch. Nothing has been pushed and the live website is unchanged.

Edit `index.html` for text and links, and `styles.css` for colors and layout. The blank hero headline can also be typed into directly in the local preview; that trial wording is saved only in the current browser. The paper artwork used by the scrolling gallery lives in `figures/`.

Open `index.html` directly in a browser for a quick preview.

When the draft is approved, merge `redesign-draft` into `main` and push `main` to publish it through GitHub Pages.
